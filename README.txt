UZ LIFE RP V3 — Android/PC SAMP-style RP prototype

FEATURES:
- 3D city
- Uzbek-style cars: Cobalt, Nexia, Damas
- login/nickname
- HOST/JOIN ENet multiplayer
- touch controls
- money/HP HUD
- job reward, shop, house, police building
- enter/exit car prototype

RUN:
1. Open this folder in Godot 4.7+
2. Run project.
3. First phone: nickname -> HOST SERVER.
4. Second phone on same Wi-Fi/hotspot: enter host phone IP -> JOIN.
5. Port: 7777.

NOTE: This is a playable prototype, not a finished commercial SAMP clone. Internet multiplayer needs a public VPS/server and firewall configuration. Original GTA/SAMP assets are not included.
